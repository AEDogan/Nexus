# 🇬🇧 English

**NEXUS** is an ultra-fast, modern, glassmorphic desktop widget bar and modular application launcher engineered with React 19, TypeScript, Vite, and Electron. It provides an elegant HUD overlay with system status monitors, customizable productivity tools, application shortcuts, and interactive widgets.

### 🌟 Key Features
- **Modern Glassmorphic HUD:** Transparent, blurred frosted-glass aesthetics with smooth micro-interactions.
- **Application Dock & Quick Launcher:** Instant one-click launch for desktop tools, web links, and custom executables.
- **Interactive Widgets:** System clock, calendar, weather forecast, quick notes, and resource tracking.
- **Lightweight & High Performance:** Built on Vite and optimized Electron runtime for minimal memory overhead.
- **Desktop Integration:** Native Windows system tray support, auto-hide, draggable overlay, and hotkeys.

### 🛠️ Tech Stack
- **Framework:** React 19, TypeScript, Vite
- **Desktop Runtime:** Electron 44+
- **Styling:** Tailwind CSS, PostCSS, Lucide Icons
- **Packaging:** electron-builder (NSIS Installer & Portable Windows Executable)

### 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run in development mode (Vite + Electron)
npm run dev

# 3. Build production Windows installer
npm run build:setup
```

# 🇹🇷 Türkçe

**NEXUS**, React 19, TypeScript, Vite ve Electron altyapısıyla geliştirilmiş, ultra hızlı, modern ve glassmorphism (buzlu cam) tasarıma sahip yeni nesil bir masaüstü araç çubuğu ve uygulama başlatıcıdır.

### 🌟 Temel Özellikler
- **Modern Glassmorphism HUD:** Şeffaf, akıcı animasyonlara ve modern estetiğe sahip buzlu cam arayüzü.
- **Uygulama Yuvası (Dock) & Hızlı Başlatıcı:** Sık kullanılan programlara, dosyalara ve bağlantılara tek tıkla anında erişim.
- **Modüler Araçlar (Widgets):** Saat, takvim, hava durumu, hızlı notlar ve sistem kaynak göstergeleri.
- **Düşük Kaynak Tüketimi:** Vite ve optimize Electron mimarisi sayesinde minimum RAM ve CPU kullanımı.
- **Masaüstü Entegrasyonu:** Windows sistem tepsisi (system tray) desteği, taşınabilir pencere ve kısayol tuşları.

### 🛠️ Teknoloji Yığını
- **Arayüz:** React 19, TypeScript, Vite
- **Masaüstü Katmanı:** Electron 44+
- **Stil & Tasarım:** Tailwind CSS, PostCSS, Lucide Icons
- **Paketleme:** electron-builder (Windows NSIS Kurulum Paketi & Taşınabilir .exe)

### 🚀 Başlangıç

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirici modunda çalıştırın (Vite + Electron)
npm run dev

# 3. Windows kurulum paketini derleyin (.exe)
npm run build:setup
```
